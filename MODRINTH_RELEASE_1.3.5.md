# Modrinth release - Custom Recipe 1.3.5 Forge

## Version type

Release

## Version number

1.3.5-forge

## Version subtitle

v1.3.5 for Minecraft 1.20.1 (Forge)

## Version changelog

### Editor settings

- Added an in-game settings screen for Custom Recipe.
- Choose whether the editor automatically adjusts the GUI scale for a clearer layout.
- Choose the default library or world opened by the editor and whether recipes load at Minecraft startup.
- Added per-setting reset buttons and clearer on/off indicators.

### Recipe browser

- Improved searches to find recipes and ingredients by displayed item name, item ID, recipe ID, and mod namespace.
- Improved support for interchangeable ingredients, including item tags and materials added by installed mods.
- Fixed ingredient previews in the recipe details screen when browsing outside a loaded world.

### Interface

- Added a settings button to the Custom Recipe editor.
- The GUI scale is restored to the player's original choice when the editor closes.

### Fixes

- Fixed item-tag ingredients, such as the planks used to craft sticks, not appearing in recipe previews.
